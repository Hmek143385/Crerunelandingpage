## 📋 ÉTAPES À SUIVRE MAINTENANT

### 1️⃣ TESTER LE SYSTÈME (1 minute)

**Accédez à cette page :**
```
/system-test
```

**Puis :**
- Cliquez sur le gros bouton rouge "Lancer tous les tests"
- Attendez que les 10 tests se terminent
- Vérifiez que tous sont **verts ✅**

Si tous les tests passent → Votre système fonctionne parfaitement !

---

### 2️⃣ CRÉER VOTRE COMPTE ADMIN (1 minute)

**Accédez à cette page :**
```
/signup
```

**Remplissez le formulaire :**
- Nom : `Admin Premunia` (ou votre nom)
- Email : `admin@premunia.fr` (ou votre email)
- Mot de passe : `[choisissez un mot de passe fort]`

**Cliquez sur "Créer mon compte"**

---

### 3️⃣ DEVENIR ADMINISTRATEUR (30 secondes)

Après l'inscription, vous serez redirigé vers :
```
/promote-admin
```

**Cliquez sur le bouton "Promouvoir en Admin"**

✅ Vous êtes maintenant administrateur avec tous les privilèges !

---

### 4️⃣ ACCÉDER AU DASHBOARD (30 secondes)

**Connectez-vous :**
```
/signin
```

**Utilisez vos identifiants créés à l'étape 2**

**Vous accédez au Dashboard :**
```
/admin
```

🎉 **FÉLICITATIONS ! Votre CRM est prêt à être utilisé !**

## 🧪 EN CAS DE PROBLÈME

### Si quelque chose ne fonctionne pas :

1. **Retournez sur `/system-test`**
2. **Relancez tous les tests**
3. **Vérifiez quel test échoue**
4. **Consultez les détails en cliquant sur "Voir les détails"**

### Problèmes Courants

**❓ Le backend ne répond pas**
- Vérifiez que le Test #1 (Health Check) passe
- Consultez les logs Supabase si disponibles

**❓ Impossible de se connecter**
- Vérifiez votre email et mot de passe
- Assurez-vous d'avoir bien créé le compte
- Le Test #4 devrait montrer votre session

**❓ Les leads ne s'affichent pas**
- Vérifiez que vous êtes bien connecté
- Le Test #6 devrait récupérer les leads
- Créez un lead de test sur la page `/`
